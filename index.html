OpenAI-compatible chat completion gateway.

Endpoint

POST /api/gateway/chat

Headers

Authorization: Bearer YOUR_KENZZ_API_KEY
Content-Type: application/json

Request body

{
  "provider": "openai",
  "model": "gpt-4o-mini",
  "messages": [
    {"role": "user", "content": "Halo Kenzz API"}
  ]
}

Supported providers

openai · groq · deepseek · together · mistral

cURL example

curl -X POST "https://YOUR-DOMAIN.vercel.app/api/gateway/chat" \\
-H "Authorization: Bearer YOUR_KENZZ_API_KEY" \\
-H "Content-Type: application/json" \\
-d '{"provider":"openai","messages":[{"role":"user","content":"Halo"}]}'
